# DuckYap
 
**Yap. Quack. Repeat.**
 
### [Play it here: www.duckyap.com](https://www.duckyap.com)

DuckYap is an online multiplayer browser game about ducks. And they yap. Personalise your duck, waddle around, chat with other ducks, find clothing items and make friends. This project spawned mostly from my motivation to learn WebSockets and I thought that building a Club Penguin-style world (a browser game I grew up on) seemed more fun than a chat app, and it was.

All the art and code is mine, models included. I had never used Blender before starting this project, and I do like how the duck models turned out.

It's currently in alpha, so it isn't perfect in terms of bugs or content, but I have plans to expand. The game's code is private, so this repo is a showcase: what it is, how it works, and a couple small code samples.
